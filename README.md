# Windows 11 Utils

Данный репозиторий представляет собой набор простых Windows 11 утилит в форматах .cpp и .exe. Вы можете скачать как исполняемый файл для использования утилиты, так и исходный код для своих проектов. Подсказки внутри кода старался писать на английском.

# Содержимое репозитория

## `src\ethernet-restart`

При запуске файла EthernetRestartUtility.exe ваш Ethernet-адаптер будет перезапущен, а в консоль выведутся логи работы. **Должен запускаться от имени администратора**.

## `src\hover-inspector`

Это инспектор интерфейса под курсором. Показывает имя, тип, AutomationId, класс, состояние UI-элемента, а также окно, процесс и PID. Программа работает в фоне и показывает информацию рядом с курсором в полупрозрачной плашке.

Модуль начинает работать сразу при запуске exe, чтобы отключить (и/или включить позже снова) - запустите exe ещё раз.

Пример вывода:

```HoverInspector
UI Element
Name: Win11Utils - HoverInspector.cpp
Type: окно
Framework: Win32
ClassName: SunAwtFrame
Enabled: True

Window
Title: Win11Utils - HoverInspector.cpp
Class: SunAwtFrame
Process: pycharm64.exe
PID: 83174
```

Удобен для отладки GUI, UI Automation, реверс-инжиниринга интерфейсов и поиска параметров окон/элементов.

## `src\drop-tray`

Этот модуль добавляет дополнительный виджет по центру у правого края экрана. DropTray.exe работает как переключатель - если виджета нет, при запуске включает, если есть, то при запуске отключает его.

В этот виджет можно скопировать (перетащить или нажать "+") до 3-х любых файлов, которые останутся там, пока вы не перетащите их из виджета куда-либо или не нажмёте по значку файла ПКМ.

Удобно при постоянной работе с различными файлами, когда требуется скопировать одни и те же объекты сразу в несколько процессов.

## `src\icon-under-the-cursor`

Данный модуль позволяет добавить любую иконку под курсором, которая есть на вашем ПК. IconUnderTheCursor.exe также работает как переключатель: если иконки нет, при запуске включает, а если есть, то при запуске отключает её.

По умолчанию ищет иконку в папке  `C:\Users\Пользователь\Pictures`, с названием ico.png. Отредактируйте код, если хотите использовать другую папку и/или файл.
