# Windows 11 Utils

Данный репозиторий представляет собой набор простых Windows 11 утилит в форматах .cpp и .exe. Вы можете скачать как исполняемый файл для использования утилиты, так и исходный код для своих проектов. Подсказки внутри кода старался писать на английском.

# Содержимое репозитория

## `src\ethernet-restart`

При запуске файла EthernetRestartUtility.exe ваш Ethernet-адаптер будет перезапущен, а в консоль выведутся логи работы. **Должен запускаться от имени администратора**.

## `src\hover-inspector`

Это инспектор интерфейса под курсором. Показывает имя, тип, AutomationId, класс, состояние UI-элемента, а также окно, процесс и PID. Программа работает в фоне и показывает информацию рядом с курсором в полупрозрачной плашке.

Модуль начинает работать сразу при запуске exe, чтобы отключить (и/или включить позже снова) - запустите exe ещё раз.

Пример вывода:

```HoverInspector
UI Element
Name: Win11Utils - HoverInspector.cpp
Type: окно
Framework: Win32
ClassName: SunAwtFrame
Enabled: True

Window
Title: Win11Utils - HoverInspector.cpp
Class: SunAwtFrame
Process: pycharm64.exe
PID: 83174
```

Удобен для отладки GUI, UI Automation, реверс-инжиниринга интерфейсов и поиска параметров окон/элементов.
